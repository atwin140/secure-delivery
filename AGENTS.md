# Working on Docs

Read `CONTEXT.md` and `README.md` before starting. Use `docs/rebuild.md` for local builds, deployment updates and recovery; these are distinct workflows.

Follow the current user request. Preserve uncommitted work, the protocol and trust boundaries documented in `docs/protocol.md` and `docs/architecture.md`. Keep credentials and runtime data outside Git. Treat dated evidence as historical until reverified.

Update the relevant documentation when behavior or deployment assumptions change. `RESTART-PROMPT.md` is the human-copyable session handoff.
