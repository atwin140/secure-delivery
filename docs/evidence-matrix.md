# Requirement-to-evidence matrix

“Local” means executed against the delivered code with synthetic data. “External” refers to the precise checks in [operator-checklist.md](operator-checklist.md), not a claimed pass. Tests establish bounded evidence, not absolute zero exposure. Exact suite results are in `evidence/unit-integration-tests.json` and `evidence/browser-tests.json`.
