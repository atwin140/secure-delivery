# Decisions

1. Node 24 LTS, TypeScript, Fastify 5, React 19, Vite 8, openid-client 6, libsodium-wrappers-sumo 0.8. Exact registry artifacts are recorded in package-lock.json and SBOM after resolution. Node 26 on this host is Current, not the production baseline. [Node release schedule](https://nodejs.org/en/about/previous-releases), [Fastify LTS](https://fastify.dev/docs/latest/Reference/LTS/), [Vite releases](https://vite.dev/releases), [openid-client](https://github.com/panva/openid-client).
2. Binary formats fix all fields and KDF settings in version 1, avoiding ambiguous JSON AAD and attacker-controlled KDF cost. Domain-separated libsodium KDF keys and crypto_auth before decrypt follow [libsodium AEAD robustness](https://doc.libsodium.org/secret-key_cryptography/aead#robustness) and [KDF guidance](https://doc.libsodium.org/key_derivation). The entire package is one [secretstream](https://doc.libsodium.org/secret-key_cryptography/secretstream). This application format is not audited.
3. NFC password normalization is consistent at both boundaries; no trimming/case folding. Fixed Argon2id settings preserve the requested profile regardless of benchmark result. [Password hashing API](https://doc.libsodium.org/password_hashing/default_phf).
4. OPFS ciphertext + exclusive Web Locks + verified per-record ciphertext hashes permit bounded memory and prove later bytes match verified bytes before output. Plaintext writes target File System Access handles only. Chromium desktop feature support is required; Firefox/Safari need separate measured compatibility. [OPFS](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API/Origin_private_file_system), [File System Access specification](https://wicg.github.io/file-system-access/).
5. Flat filenames and ZIP STORE reduce archive parsing surface. ZIP32 suffices below 1 GiB/100 entries. Output CRC32 is not a cryptographic integrity mechanism. [PKWARE APPNOTE](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT).
6. A BFF with Postgres session verifiers avoids browser OAuth tokens and extra Redis infrastructure. 15-minute absolute sessions bound stale role decisions. ID-token and access-token signatures, issuer and client audience are validated; Keycloak must add this BFF audience to access tokens. [Keycloak OIDC](https://www.keycloak.org/securing-apps/oidc-layers).
7. Whole-object immutable retries use a ciphertext SHA-256, never a plaintext hash. S3 multipart is internal implementation only; recipient downloads are always proxied. Conservative S3 capability probes and operator attestations replace assumed AWS lifecycle equivalence. Configuration calls bucket provisioning class **S3 storage class**; it does not mean an AWS object tier.
8. DB checks per network chunk, 250ms watchdogs, local expiry deadlines and PostgreSQL NOTIFY provide revocation propagation across replicas. Fail closed on DB uncertainty. Already transmitted bytes cannot be recalled. Single Postgres is not HA.
9. Synchronous Graph mail keeps addresses out of databases/queues. Use Exchange Application RBAC scoped to the dedicated mailbox, audit/remove additive tenant-wide Entra Mail.Send grants, and use saveToSentItems=false. Accepted response is not proof of delivery. [Graph sendMail](https://learn.microsoft.com/en-us/graph/api/user-sendmail), [Exchange application RBAC](https://learn.microsoft.com/en-us/exchange/permissions-exo/application-rbac).
10. Safe restore invalidates all restored deliveries and requires explicit re-enable only after object reconciliation. This sacrifices usability to avoid resurrecting revocations missing from daily backups. Metadata backup RPO is up to 24 hours, retention 30 days; document buckets excluded from all backup/version retention systems.
11. The target is OpenShift, and this request authorizes local work only. No Sites deployment, production changes or live messages are performed. Container image digests and actual cluster/gateway/provider observations are operator prerequisites where the local environment cannot establish them.

## Isolated deployment findings (2026-09-12)

- Use namespace-scoped TLS/authenticated Distribution for test image builds because the ACM integrated registry is Removed and local Podman engines cannot be reached. No cluster-wide registry change is made. Build on the worker with observed spare disk after eviction on a low-disk worker.
- ODF RGW represents absent bucket replication as HTTP 200 with an empty Role and no Rules. Accept this semantically empty envelope; reject any role, rule (including disabled rules), unknown configuration field, or uncertain API outcome. The real gateway and negative tests provide evidence. Ceph also has zone-level sync policy, which remains a separate operational check: [Ceph multisite sync policy](https://docs.ceph.com/en/squid/radosgw/multisite-sync-policy/).
- Resolve required egress destinations from inside the cluster as well as the operator workstation. ACM uses split DNS; the test policy permits the observed internal identity address explicitly.
- Health checks connect to the current replica on loopback with the service DNS name as TLS SNI/verification name. Probing the Service deadlocks readiness before its endpoints are ready.
- Support explicit `LINK_EMAIL_ENABLED=false` for installations without mail provisioned. Default remains enabled with strict Graph configuration. Disabled mode rejects the email API, hides its form and makes no Graph requests.
- Use a separate test Keycloak with TLS and the `basic` scope. The existing shared Keycloak Route has an HTTP backend, so it was not modified or used for the strict-TLS test. [Keycloak container and import configuration](https://www.keycloak.org/server/containers).
